# Referências Visuais e de Interação

## Dog Dress Up (JS Drag & Drop)
**Fonte:** post de Instagram / JavaScript Project
**Conceito:** Personagem central + painel lateral com categorias de acessórios (olhos, boca, óculos, chapéu). Arrastar e soltar sobre o personagem.
**Adaptação para o Duvid:**

### Globinho Dress Up — dentro dos textos de aula
- Personagem: Globinho pixel art no centro
- Categorias temáticas por bloco de aula:
  - Cartografia → bússola, lupa, mapa, régua
  - África → máscara, turbante, tambor, savana
  - Clima → nuvem, sol, chuva, neve, furacão
  - Hidrografia → gota, barco, peixe, represa
  - Biogeografia → folha, animal, bioma, árvore
- Mecânica: aluno monta o Globinho temático no início ou fim do texto
- Recompensa: +2 globinhos por interagir
- Compartilhável: "Meu Globinho de Cartografia" → Stories @duvidgeo

### Implementação técnica
- HTML/CSS/JS puro (drag & drop API nativa ou pointer events)
- Globinho base em PNG transparente
- Acessórios em PNG separados (bolsista cria no Aseprite)
- Canvas API para exportar a imagem final para compartilhar
- Embutido dentro do texto da aula como seção interativa

**Arquivo de referência:** imagem salva na conversa do Claude (2026-06-20)
